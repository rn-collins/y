# Psychedelic Harm Reduction Governance Readiness

An NSAG assessment instrument, published as a single self-contained page.

## What this establishes

That an organisation working in psychedelic harm reduction can be walked through a
structured readiness assessment and receive a scored result, without any data leaving
the page.

## What it does not establish

It is an assessment instrument, not an accreditation. A result is a self-reported
readiness position, not a certification, an audit finding, or clinical guidance. The
current advisory work is on the [NSAG site](https://nsag-site.vercel.app).

## Repository

One file, `index.html`, with the styles, scoring and result rendering inline. No build
step and no dependencies.

The repository name is an accident of scaffolding, kept because nothing has needed to
link to it.
